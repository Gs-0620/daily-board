# daily-board

- `index.html` — 孕产时间线 · 温馨版（主页面，星月夜灯风）
- `classic.html` — 孕产时间线 · 原版（米纸红章风）
- `board.html` — 每日信息板（数据在 `data.json`）

账单 / 心情可在首页填写：使用共同密码登录，新增记录存入 Cloudflare Durable Object，不写入公开仓库；30天登录会话，爸爸/妈妈可分别记录。首次密码设置使用专用链接，密码只保留 PBKDF2 派生值。页面静态历史仍公开可见。也可通过 MyFlicker 对话更新静态历史。

公网地址：<https://gs-0620.github.io/daily-board/>
